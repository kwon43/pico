# PICO 프로젝트 20302 권민솔
# 스마트 가방 준비물 검사기 (Smart Bag Checker)
## 1. 프로젝트 소개

**스마트 가방 준비물 검사기**는 학생들이 학교에 필요한 준비물을 빠뜨리는 문제를 해결하기 위해 제작한 피지컬 컴퓨팅 프로젝트이다.

Raspberry Pi Pico와 인공지능 비전 센서인 HUSKYLENS를 활용하여 가방에 넣는 물건을 인식하고, OLED 디스플레이에 준비물 확인 상태와 누락된 물건을 표시한다.

특히 버튼과 LED 조명을 이용하여 학생이 간편하게 검사 과정을 시작하고 종료할 수 있도록 설계하였다.

## 2. 제작 동기

학교에 갈 때 교과서, 공책, 필통, 휴대폰 등의 준비물을 빠뜨리는 경우가 있다.

일반적인 준비물 체크리스트는 사용자가 직접 확인해야 한다는 불편함이 있다.

이 문제를 해결하기 위해 **카메라가 물건을 인식하고 준비 여부를 자동으로 기록하는 가방**을 제작하고자 하였다.

## 3. 주요 기능

###  인공지능 물체 인식

- HUSKYLENS의 `Object Classification` 기능을 사용한다.
- 미리 학습시킨 물건을 각 ID로 구분한다.
- 인식된 물건을 확인 완료로 처리한다.

###  실시간 준비물 체크리스트

- OLED에 준비물 목록을 표시한다.
- 아직 확인하지 않은 물건은 빈 체크박스로 표시한다.
- 확인한 물건은 체크 표시(✓)로 구분한다.
- 확인한 준비물 개수와 전체 준비물 개수를 함께 표시한다.

### ③ 중복 인식을 이용한 확인 취소

- 물건을 처음 인식하면 확인 상태가 된다.
- 해당 물건을 카메라 시야에서 뺐다가 다시 인식시키면 확인이 취소된다.
- 같은 물건을 계속 비추는 동안에는 반복해서 확인 상태가 바뀌지 않도록 처리한다.

###  이어서 검사하기

- 검사 종료 후 빠진 물건이 있으면 기존 확인 기록을 유지한 상태로 검사를 다시 시작할 수 있다.
- 초록 버튼을 길게 누르면 기록을 초기화하여 새로운 검사를 시작할 수 있다.

###  누락 준비물 표시

- 빨간 버튼을 누르면 검사가 종료된다.
- 빠진 준비물이 있다면 OLED에 `MISSING:`과 물건 이름을 표시한다.
- 모든 준비물이 확인되었다면 `ALL READY!`를 표시한다.

###  LED 조명

- 어두운 가방 내부에서도 카메라가 물건을 인식할 수 있도록 LED 조명을 사용한다.
- 검사 시작 시 LED가 켜지고 검사 종료 시 꺼진다.

## 4. 사용 부품

| 부품 | 역할 |
|---|---|
| Raspberry Pi Pico | 전체 시스템 제어 |
| Grove Shield for Pi Pico | 센서와 부품 연결 |
| HUSKYLENS | 인공지능 물체 인식 |
| SSD1315 OLED 디스플레이 | 준비물 확인 상태 표시 |
| Grove Dual Button | 검사 시작 및 종료 |
| Grove RGB LED Stick V1.0 (WS2813) | 가방 내부 조명 |
| USB 보조배터리 | 휴대용 전원 공급 |
| 플라스틱 지지판 및 케이스 | 부품 고정 및 보호 |

## 5. 하드웨어 연결

| 부품 | Raspberry Pi Pico 핀 |
|---|---|
| HUSKYLENS SDA | GP6 |
| HUSKYLENS SCL | GP7 |
| OLED SDA | GP8 |
| OLED SCL | GP9 |
| 초록 버튼 | GP16 |
| 빨간 버튼 | GP17 |
| LED 스틱 | GP18 |

- HUSKYLENS는 I2C1을 사용한다.
- OLED는 SoftI2C 방식으로 연결한다.
- WS2813 LED에는 별도의 신호 타이밍을 적용한다.

## 6. 물체 학습 방법

HUSKYLENS의 `Object Classification` 모드를 사용하여 다음 물건을 학습한다.

| 학습 ID | 대상 |
|---|---|
| ID1 | PHONE (휴대폰) |
| ID2 | NOTEBOOK (공책) |
| ID3 | PENCILCASE (필통) |
| ID4 | BLACK BAG (빈 가방 배경, 선택 사항) |

동일한 물건의 정면, 측면, 기울어진 모습 등 여러 각도를 학습하여 인식률을 높이고자 하였다.

검정색 가방 내부를 별도의 배경 ID로 학습하여 빈 가방을 준비물로 잘못 인식하는 현상을 줄이는 방법도 적용 또는 실험할 수 있다.

배경 ID는 필수 준비물 목록에 포함하지 않는다.

## 7. 시스템 작동 과정

1. 보조배터리에서 Pico에 전원을 공급한다.
2. OLED에 `ON`이 표시되고 LED는 꺼진 상태로 대기한다.
3. 초록 버튼을 누르면 검사가 시작되고 LED가 켜진다.
4. HUSKYLENS가 물건을 인식하면 OLED 체크리스트에 확인 표시가 나타난다.
5. 같은 물건을 카메라에서 뺐다가 다시 보여주면 확인 상태가 취소된다.
6. 빨간 버튼을 누르면 검사를 종료하고 LED가 꺼진다.
7. OLED에 빠진 준비물 또는 모든 준비 완료 메시지가 나타난다.

## 8. 버튼 조작 방법

| 조작 | 기능 |
|---|---|
| 초록 버튼 짧게 | 검사 시작 / 이어서 검사 |
| 초록 버튼 2초 길게 | 기록 초기화 후 새 검사 |
| 검사 중 빨간 버튼 | 검사 종료 및 결과 표시 |
| 검사 종료 후 빨간 버튼 | 동작 없음 |

## 9. 프로그램 구성

프로그램은 MicroPython으로 작성하며 Thonny IDE를 사용한다.

주요 파일은 다음과 같다.

- `main.py` : 전체 검사 프로그램
- `ssd1306.py` : OLED 화면 제어 라이브러리
- `README.md` : 프로젝트 설명 문서

`main.py`와 필요한 라이브러리를 Raspberry Pi Pico 내부에 저장하면 전원을 공급할 때 프로그램이 자동 실행되도록 구성할 수 있다.

## 10. 가방 내부 설치 방법

일반적인 천 소재 책가방은 형태가 쉽게 변하기 때문에, 전자부품을 직접 부착하기보다 얇은 플라스틱 지지판을 사용한다.

- HUSKYLENS: 가방 입구 안쪽에서 준비물을 향하도록 고정
- LED 스틱: 카메라 옆에 설치하여 준비물을 비추도록 배치
- OLED와 버튼: 가방 입구에서 확인하고 조작하기 쉬운 위치에 설치
- Raspberry Pi Pico와 Grove Shield: 보호 케이스에 넣어 가방 안쪽 지지판에 고정
- 보조배터리: 가방 옆주머니에 설치
- 연결 케이블: 가방 가장자리를 따라 정리하고 벨크로 타이로 고정

이를 통해 가방 내부 공간을 최대한 확보하고, 부품을 분리하거나 수리하기 쉬운 구조를 목표로 한다.

## 11. 제작 과정에서 해결한 문제

### OLED 통신 문제

OLED가 정상적으로 표시되지 않는 문제가 발생하였다.

I2C 연결 방식을 점검하고 SoftI2C를 적용하여 화면이 정상적으로 표시되도록 수정하였다.

### HUSKYLENS 물체 분류 기능

초기 펌웨어에서는 필요한 물체 분류 기능을 사용할 수 없어 HUSKYLENS 펌웨어를 업데이트하였다.

업데이트 이후 `Object Classification` 기능을 활용하여 물건을 학습하는 방향으로 개발하였다.

### LED 제어 문제

LED 스틱이 켜진 상태를 유지하고 버튼 명령에 반응하지 않는 문제가 있었다.

WS2813 LED의 제어 타이밍을 확인하고 별도의 타이밍 값을 적용하도록 코드를 수정하였다.

### 빈 가방 오인식 문제

가방 내부의 검정색 배경을 준비물로 잘못 인식하는 현상이 발생하였다.

이를 줄이기 위해 빈 가방 배경을 별도 ID로 학습시키는 방법과 반복 인식 확인 방식을 검토하였다.

## 12. 프로젝트의 한계점

- 물건이 서로 겹쳐 있거나 카메라 시야에서 벗어나면 인식이 어려울 수 있다.
- 조명과 카메라 각도에 따라 인식 정확도가 달라질 수 있다.
- 같은 물건을 다시 보여주는 방식은 물건이 실제로 가방에서 빠져나갔는지를 자동으로 판단하는 것과는 다르다.
- 빈 가방 배경을 학습하더라도 모든 오인식을 방지할 수 있는 것은 아니다.
- 보조배터리와 각 센서의 전원 공급 상태에 따라 작동이 달라질 수 있다.

## 13. 향후 개선 방향

- 가방 내부 조명 자동 조절 기능
- 물건을 넣는 동작과 꺼내는 동작을 구분하는 기능
- 요일별 시간표에 따른 준비물 목록 변경
- 물체 인식 정확도 개선 및 오인식률 측정
- 회로와 케이블의 소형화 및 탈착식 설치 구조 개선
- 음성 또는 진동을 이용한 누락 준비물 알림

## 14. 기대 효과

이 프로젝트를 통해 학생들이 준비물을 빠뜨리는 일을 줄이고, 학교에 가기 전 준비 상태를 빠르게 확인할 수 있을 것으로 기대한다.

또한 인공지능 이미지 인식, 센서 통신, 디스플레이 제어 및 피지컬 컴퓨팅 기술을 하나의 시스템에 적용하는 경험을 얻을 수 있다.

**핵심 목표는 단순히 물건을 인식하는 기계를 만드는 것이 아니라, 학생의 일상적인 불편함을 해결하는 실용적인 스마트 가방을 구현하는 것이다.**
